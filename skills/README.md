# Agent skills

Reusable agent instructions for Akan Reports. Paths are relative to the repository root. Any coding agent can read these; they are not tied to a single IDE.

| Skill | When to use |
|-------|-------------|
| [update-pulse-stats](update-pulse-stats/SKILL.md) | Refresh homepage Pulse figures in `data/pulse.yaml` |

A Cursor-oriented copy of `update-pulse-stats` also lives under `.cursor/skills/` for IDE discovery. Prefer this `skills/` directory as the canonical, portable source when editing the skill.
