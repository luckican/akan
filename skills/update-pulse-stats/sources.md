# Pulse preferred sources

Use these as the first stop. If a URL moves, search the organisation’s official site rather than inventing a figure.

## USD / GHS

- Bank of Ghana, Daily interbank FX rates: https://www.bog.gov.gh/treasury-and-the-markets/daily-interbank-fx-rates/
- Prefer the USD row mid / weighted median (or buy/sell midpoint if only those are published).
- State the rate type in the run report (e.g. “BoG interbank mid”).
- Avoid unlabelled parallel-market or dealer screenshots as the sole source.

## Inflation

- Ghana Statistical Service: https://statsghana.gov.gh/
- Use **headline CPI inflation, year-on-year**, for the latest published month.
- Change = difference vs the previous month in **percentage points**.

## Cocoa / tonne

- Prefer ICE Futures US cocoa continuous contract in **USD per metric tonne**.
- Acceptable aggregators when they clearly attribute ICE US cocoa (verify the as-of stamp).
- Do not mix London (£/t) and New York ($/t) without converting and labelling; this Pulse slot expects a **dollar** figure like `$6,457`.

## GSE Composite

- Ghana Stock Exchange: https://gse.com.gh/
- Use the Composite Index **official close** and previous close for the daily % change.
- Round the displayed level to the nearest whole number.

## Secondary corroboration

Reuters, Bloomberg, or established Ghana financial desks may corroborate when the primary site is down or unclear. The run report should still name the primary figure’s origin when possible.
